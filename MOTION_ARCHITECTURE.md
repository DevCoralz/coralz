# Coralz Motion Architecture

## Global
- Page-entry curtain
- Smooth desktop scrolling with native mobile behavior
- Cursor aura
- Scroll progress
- Command navigation (`Cmd/Ctrl + K`)

## Navigation
- Keyboard-first command palette
- Escape/backdrop dismissal
- Filterable route list

## Project storytelling
- Full-height project scenes
- Scroll-derived media scale/translation
- Perspective grid
- Hover light sweep
- Case-study affordance
- Per-project metadata

## Depth
- Pointer-driven product-card tilt
- Magnetic CTA controls
- Hero pointer parallax

## Accessibility
Every decorative animation checks `prefers-reduced-motion`.
Mobile disables desktop-specific smooth scrolling and cursor UI.
